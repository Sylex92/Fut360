# ADR 0003 — GLB/glTF 2.0 como formato runtime

## Estado
Aceptado inicialmente.

## Decisión
Blender conserva la fuente editable. El runtime consume GLB.

## Razón
Formato compacto, portable y compatible con animación esquelética y animación de nodos.

## Consecuencia
Cada exportación debe validarse y generar un manifiesto.
