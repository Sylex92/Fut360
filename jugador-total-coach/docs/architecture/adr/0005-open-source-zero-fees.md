# ADR 0005 — Decisión histórica sustituida

Estado: sustituido por ADR 0008, 2026-09-24.

La versión anterior exigía exclusivamente software libre/de código abierto y ausencia de pagos obligatorios. El usuario corrigió la primera condición: ahora admite licencias gratuitas no abiertas. Se mantiene el objetivo de costo cero y la operación local. Las reglas activas están en ADR 0008 y `ZERO_COST_AND_GROWTH_POLICY.md`.
