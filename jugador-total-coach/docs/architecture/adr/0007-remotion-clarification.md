# ADR 0007 — Aclaración histórica de Remotion

Estado: decisión de excepción pendiente sustituida por ADR 0008, 2026-09-24.

Se distinguió gratuidad de open source. La nueva regla del usuario permite herramientas gratuitas no abiertas; por tanto ya no es necesaria una excepción FOSS para evaluar Remotion. La exportación sigue fuera del MVP1 y ninguna dependencia se instala sin revisar versión, condiciones y utilidad.

Ver ADR 0008 y `docs/research/REMOTION_LICENSE_REVIEW.md` para la decisión y evidencia activas.
