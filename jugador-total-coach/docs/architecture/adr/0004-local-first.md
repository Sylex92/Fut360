# ADR 0004 — Local-first

## Estado
Aceptado inicialmente.

## Decisión
La sesión y los registros se ejecutan y guardan localmente.

## Razón
El entrenamiento no debe depender de conectividad ni de una cuenta.

## Consecuencia
Se requiere exportación/importación futura y un puerto de persistencia que permita agregar nube sin cambiar el dominio.
