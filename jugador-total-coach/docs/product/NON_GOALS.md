# No objetivos del MVP1

El MVP1 no intenta:

- ser una red social;
- sustituir entrenador, fisioterapeuta o médico;
- generar automáticamente cualquier ejercicio;
- crear un gemelo digital exacto del usuario;
- representar a Bellingham o Firmino;
- medir calorías con precisión;
- recomendar cargas a partir de wearables;
- simular partidos;
- tener microservicios;
- soportar múltiples organizaciones;
- monetizar;
- renderizar cada sesión como video MP4.

Estas capacidades pueden investigarse después de validar la sesión 3D completa.
