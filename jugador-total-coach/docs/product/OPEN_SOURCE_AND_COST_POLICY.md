# Política anterior — sustituida

La obligación de utilizar exclusivamente software open source dejó de ser vigente por corrección expresa del usuario.

Leer `docs/product/ZERO_COST_AND_GROWTH_POLICY.md` y ADR 0008. Se permiten licencias gratuitas no abiertas cuando cubren el uso previsto sin pagos obligatorios. Este archivo conserva la ruta histórica; no añade condiciones.
