# Prompt 08 — Offline, persistencia y feedback

Implementa:
- instalación PWA;
- cache de app y assets del MVP;
- persistencia local detrás de un puerto;
- recuperación básica de sesión;
- registro final:
  - completada/incompleta;
  - duración;
  - RPE;
  - rodilla antes/después;
  - notas;

Prueba:

- recargar durante una sesión;
- terminar y consultar el historial;
- eliminar datos locales.
